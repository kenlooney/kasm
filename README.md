# Kasm — Ken's Assembler

Kasm is a small C11 assembler with a limited x86-64 instruction set and an
emerging x86-16 (real-mode) subset. It owns source text, lexes tokens,
parses expressions and statements, validates operands, assigns image
offsets, resolves labels and relocations, emits machine-code bytes, and can
decode supported instruction images back into a listing. It can also
generate Windows x64 COFF objects and raw data images with assembly-time
repetition.

The current source version is **0.34.0 (in development)**. All detailed
documentation now lives in the **[Kasm Dev Log](https://kasm.kennethlooney.com/)**,
an [mdbook](https://rust-lang.github.io/mdBook/) built from
[`devlog/`](devlog/src/introduction.md). This README is intentionally short —
use it to find the right page in the book.

## Building the journal locally

```powershell
cd devlog
mdbook build
```

The `publish-devlog` job in
[`.github/workflows/ci.yml`](.github/workflows/ci.yml) builds this book and
deploys it to GitHub Pages on every push to `main`, publishing at
`https://kasm.kennethlooney.com/`.

## Quick start

```powershell
.\build\windows-debug\Debug\kasm.exe example.asm
```

```bash
./build/GCC-debug/kasm example.asm
```

For `mov eax,42;`, both print:

```text
B8 2A 00 00 00
0000: mov eax, 42
Decoding successful.
```

See [Building and testing](devlog/src/reference/building-and-testing.md) for
how to configure and build from a source checkout, or
[Using a release](devlog/src/reference/releases.md) to start from a
downloaded ZIP instead.

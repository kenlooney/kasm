# 0.37.0 — A Focused Release Archive

Version 0.37.0 is a documentation-only release. The assembler, output formats,
instruction encodings, and command-line behavior are unchanged from 0.36.0.

## Why reduce the release list?

Kasm developed through many deliberately small milestones. Those versions are
valuable as a learning record, but a separate downloadable package for every
small historical step makes the GitHub Releases page harder to scan. Users
looking for a binary generally need a recent milestone rather than every early
archive.

The project now retains downloadable packages for the seven most recent GitHub
Releases. When a new release is published, the oldest release page and its
uploaded binary packages may be removed to maintain that window.

## What remains available?

Removing a GitHub Release does not erase Kasm's development history. Historical
Git tags and commits remain in the repository, and this journal records the
version-by-version roadmap. A reader can inspect or check out an older tagged
source revision even when its prebuilt ZIP is no longer retained.

The project therefore has three complementary records:

- GitHub Releases provide recent downloadable Windows and Linux packages.
- Git tags and commits preserve exact historical source.
- This development journal explains what changed and why.

No implementation or test changes accompany 0.37.0.
